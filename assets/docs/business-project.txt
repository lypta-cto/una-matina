Project Development Priorities
A clear sequence prevents unnecessary purchases and premature expansion.



    1. Complete the farmers market launch                                                 2. Define the exact event service scope



    3. Build an internal costing system                                                   4. Finalize the modular live station specification



    5. Purchase core reusable inventory                                                   6. Build the vendor & partner network



    7. Build a staffing pool and service standards                                        8. Contracts, policies & checklists



    9. Styled portfolio shoots                                                            10. Launch materials + website later




                   Every new purchase should answer three questions: Is it reusable? Does it improve the guest experience? Can it be used profitably?
